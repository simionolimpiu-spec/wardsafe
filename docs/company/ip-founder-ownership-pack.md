## External Sharing Checklist

### Can Share

- [ ] Simulation preview link, if authorised
- [ ] Demo script
- [ ] High-level workflow problem
- [ ] Simulation-safe product concept
- [ ] Non-confidential screenshots or walkthroughs
- [ ] Clear statement that the preview is not clinically validated

### Do Not Share Without Review

- [ ] Proprietary implementation details
- [ ] Deployment secrets
- [ ] Live Lambda tokens
- [ ] Private repo access
- [ ] Unprotected invention details not yet logged
- [ ] Any real patient data
- [ ] Any NHS internal material not cleared for sharing
- [ ] Claims of clinical validation, NHS readiness, safety impact, diagnostic accuracy, or prediction performance
