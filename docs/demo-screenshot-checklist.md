# SafeFlow demo screenshot checklist

Use this checklist when capturing manual screenshots for reviewer materials.

## Safe screenshots to capture

- boundary or opening screen with simulation-only wording visible
- fictional ward safety board
- handover or discharge-readiness view
- explainable risk-support reasons
- simulation report summary
- fictional scenario coverage summary
- audit and learning timeline
- safety boundary wording

## Pre-capture checks

- no real patient data visible
- no NHS logo visible
- no unsafe clinical wording visible
- fictional names and fictional data only
- browser address bar may be cropped if needed
- each screenshot should be labelled `simulation-only prototype`
