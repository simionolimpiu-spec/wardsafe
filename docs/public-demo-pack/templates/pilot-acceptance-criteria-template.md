## Go / No-Go Criteria

Go if:

- Safety review conditions met.
- Users can complete target scenarios.
- Audit trail is complete.
- No unresolved high-risk hazards.

No-go if:

- Users misunderstand SafeFlow as autonomous clinical advice.
- AI output includes unsafe action wording.
- Missing data is presented as normal.
- Access control or audit logging fails.
