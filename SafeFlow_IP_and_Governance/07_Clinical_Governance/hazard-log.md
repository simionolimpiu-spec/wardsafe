# Initial Hazard Log

| Hazard | Example risk | Mitigation direction |
| --- | --- | --- |
| Incorrect prioritisation | An urgent task appears lower priority than routine work | Human review, audit trail, escalation override |
| Missed escalation | A warning is not seen by the nurse or site team | Visible escalation status and acknowledgement tracking |
| False reassurance | The dashboard looks calm despite deterioration | Clear disclaimer, no replacement of clinical judgement |
| Data mismatch | The wrong patient or context is displayed | Identity validation and integration controls |
| Alert fatigue | Too many prompts create noise | Configurable thresholds and user testing |
| Workflow duplication | Staff document twice in different places | Interoperability roadmap and shadow-mode pilot first |

This is a starter log only. It is not a safety case.
