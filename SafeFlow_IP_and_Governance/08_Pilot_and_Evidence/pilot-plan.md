# Pilot And Evidence Plan

Recommended sequence:

1. Prototype review with 3 to 5 nurses or ward leaders.
2. Workflow mapping for one ward pathway.
3. Simulation or tabletop testing using fictional patient scenarios.
4. Shadow-mode evaluation with no clinical decision-making impact.
5. Governance review with digital, IG, clinical safety and transformation leads.
6. Single-ward controlled pilot, only if approved.

Suggested measures:

| Domain | Measure |
| --- | --- |
| Flow visibility | Time to identify discharge blockers |
| Escalation | Clarity of escalation status |
| Handover | Completeness of key handover fields |
| Workload | Perceived duplication and cognitive burden |
| Safety | Near-miss themes, escalation delays, missed tasks |
| Usability | SUS score or short NHS-style usability feedback |

Keep the pilot framed as governed learning, not live-service rollout.
