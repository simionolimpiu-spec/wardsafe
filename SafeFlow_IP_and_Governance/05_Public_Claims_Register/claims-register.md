# Public Claims Register

| Claim on website | Evidence | Status |
| --- | --- | --- |
| SafeFlow is early-stage | Simulation-only website, no live patient data, no deployed clinical system | Safe |
| Built for NHS adoption | Governance and pilot roadmap are shown, but no approval is claimed | Safe if phrased carefully |
| Governance-aware | DTAC, DCB0129, DCB0160, DSPT, accessibility and human oversight are documented as roadmap items | Safe |
| Improves patient flow | Intended benefit only, not yet measured | Needs evidence |
| Reduces harm or delay | No evaluation data yet | Unsafe until evaluated |
| NHS-approved | No NHS approval exists or is claimed | Never say this |

Wording rules:

- use "early-stage", "simulation-only", "governance-aware", and "roadmap" language
- avoid "approved", "validated", "certified", "deployed", "endorsed", or "proven" unless you have written evidence
- do not imply DTAC pass, CE/UKCA status, or NHS endorsement
